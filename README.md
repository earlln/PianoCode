# PianoCode

피아노 코드 사전과 악보 코드 변환기를 하나로 묶은 안드로이드 앱입니다.
모든 코드를 건반 그림으로 보여 주고, 악보 사진 속 코드를 원하는 스케일로 바꿔 줍니다.

## 기능

### 1. 코드 목록 — 기본 코드와 모든 변화 코드

17개 근음(C부터 B까지, 이명동음 표기 포함) × 55종류의 코드 = **935개**의 코드를 담고 있습니다.
코드는 일곱 계열로 묶여 있고, 각 계열은 기본 코드 하나와 그로부터 파생된 변화 코드로 이루어집니다.

| 계열 | 기본 코드 | 변화 코드 예시 |
| --- | --- | --- |
| 메이저 | `C` | `C6` `C6/9` `Cmaj7` `Cmaj9` `Cmaj11` `Cmaj13` `Cadd9` `Cmaj7#11` `Cmaj7#5` … |
| 마이너 | `Cm` | `Cm6` `Cm7` `Cm9` `Cm11` `Cm13` `CmMaj7` `Cm(add9)` `Cm7#5` … |
| 도미넌트 | `C7` | `C9` `C11` `C13` `C7b5` `C7#5` `C7b9` `C7#9` `C7#11` `C7b13` `C7alt` … |
| 디미니쉬 | `Cdim` | `Cdim7` `Cm7b5` `Cm9b5` |
| 오그멘티드 | `Caug` | `C+Maj7` |
| 서스펜디드 | `Csus4` | `Csus2` `C7sus4` `C9sus4` `Cmaj7sus4` `C7sus2` `Csus4add9` |
| 파워 | `C5` | — (3음이 없어 변화 코드가 없습니다) |

### 2. 건반 위치 그림

모든 코드에 대해 실제로 눌러야 할 건반을 그림으로 그립니다.

- **근음 / 구성음 / 텐션 / 베이스**를 색으로 구분
- **자리바꿈(전위)** 별로 건반 모양이 바뀝니다 — 루트 포지션부터 3전위까지
- 화면 폭에 맞춰 필요한 옥타브만큼 자동으로 넓어집니다

### 3. 스케일 & 다이아토닉 코드

12개 스케일(메이저, 내추럴/하모닉/멜로딕 마이너, 5개 교회선법, 펜타토닉, 블루스)의
구성음을 건반에서 확인하고, 그 조성의 다이아토닉 3화음·7화음을 로마숫자와 함께 봅니다.

### 4. 악보 코드 변환 — 원하는 스케일로

악보 사진을 고르면 기기 안에서 글자를 인식해 코드 심볼을 찾아내고,
원하는 조성으로 바꿔 **원본 이미지 위에 다시 그려 줍니다.**

1. 악보 이미지를 가져옵니다. 네 가지 경로가 있습니다.
   - **최근 사진** — 안드로이드 기본 사진 선택기 (권한 불필요)
   - **갤러리 앱에서 찾기** — 삼성 갤러리·구글 포토의 사진 / 앨범 / 스토리 탐색
   - **파일에서 찾기** — 내 파일, 드라이브, 다운로드 폴더
   - **카메라로 촬영** — 악보를 지금 찍어서 바로 변환
2. 앱이 코드 심볼을 찾아내고 원래 조성을 추정합니다
3. 변환 방식과 목표 스케일을 고릅니다
   - **조옮김** — 모든 코드를 같은 간격만큼 이동합니다. 화성 관계는 그대로입니다.
   - **스케일 맞춤** — 각 코드의 도수를 유지한 채 목표 스케일의 화성으로 바꿉니다.
     장조 ↔ 단조 변환처럼 코드의 성질까지 바뀌어야 할 때 씁니다.
4. 인식된 코드 목록에서 잘못 잡힌 항목을 꺼 둡니다
5. 변환해 갤러리에 저장하거나 공유합니다

새로 쓴 코드에만 색이 입혀집니다. 원래 조성으로 남은 코드는 악보 원래 색 그대로라,
무엇이 바뀌고 무엇이 안 바뀌었는지 한눈에 구분됩니다.

자동으로 못 바꾼 코드는 **직접 고칠 수 있습니다.** `직접 고치기`를 켜고 결과 그림에서
고칠 코드 위를 손가락으로 감싸듯 그으면 넣을 코드를 고르는 창이 열립니다.
그 자리에서 글자는 읽었지만 코드로 쓰지 못한 경우에는 변환된 코드가 바로 제시되므로
한 번 더 누르면 끝납니다.

표시 색은 그 악보의 잉크색을 재서 **가장 다른 색**으로 자동 선택됩니다 —
보라색으로 인쇄된 악보에 보라색으로 표시하면 묻히기 때문입니다.
보라·빨강·파랑·초록·주황 중에서 직접 고를 수도 있고,
`바뀐 코드를 색으로 구분` 스위치를 끄면 악보의 원래 잉크색으로 씁니다.

> 글자 인식은 ML Kit의 **기기 내 처리** 모델을 사용합니다. 사진은 서버로 전송되지 않습니다.

> **바뀌는 것과 바뀌지 않는 것** — 이미지 위에 덧그리는 방식이라 **코드 심볼만** 바뀝니다.
> 오선보의 조표와 음표는 원본 그대로 남습니다. 결과 이미지 위쪽 띠에 이 사실과
> 원래 조성 → 바뀐 조성이 적힙니다. 읽지 못한 코드가 있으면 변환 전에 개수를 알려 주므로,
> 한 악보에 두 조성이 섞이는 일을 피할 수 있습니다.

## 설치

[릴리즈 페이지](https://github.com/earlln/PianoCode/releases)에서 최신 APK를 내려받아 설치하세요.
`설정 → 보안 → 출처를 알 수 없는 앱`을 허용해야 할 수 있습니다.

- 최소 지원: Android 7.0 (API 24)
- 타깃: Android 15 (API 35)

## 프로젝트 구조

```
PianoCode/
├── core-music/          순수 Kotlin 음악 이론 엔진 (안드로이드 의존성 없음, 단위 테스트 대상)
│   └── music/
│       ├── Note.kt          음이름 표기 — 글자 + 임시표
│       ├── ChordQuality.kt  55종 코드의 도수 공식과 계열
│       ├── Chord.kt         구성음, 건반 보이싱, 자리바꿈
│       ├── Scale.kt         조성, 조표, 다이아토닉 화성
│       ├── ChordParser.kt   악보에 적힌 코드 심볼 읽기
│       ├── Transposer.kt    조옮김 · 스케일 맞춤 · 조성 추정
│       └── ChordLibrary.kt  화면이 훑는 카탈로그
└── app/                 Jetpack Compose 안드로이드 앱
    ├── ui/              화면과 건반 렌더러
    ├── sheet/           악보 인식(ML Kit)과 이미지 위 다시 그리기
    └── util/            이미지 불러오기 · 저장 · 공유
```

음이름을 소리(pitch class)가 아니라 **악보에 적히는 글자**로 다루는 것이 이 엔진의 핵심입니다.
그래서 D♭ 장조에서는 `D♭`, A 장조에서는 `C♯`가 나오고, `C7`의 7음은 항상 `B♭`(`A♯`가 아니라)입니다.

## 빌드하기

```bash
./gradlew :core-music:test      # 음악 이론 엔진 단위 테스트
./gradlew :app:assembleDebug    # 디버그 APK
./gradlew :app:assembleRelease  # 릴리즈 APK
```

Android SDK 35와 JDK 17이 필요합니다.

## 버전 관리와 릴리즈

버전은 `version.properties` 한 곳에서만 관리합니다.

```properties
VERSION_NAME=1.0.0
VERSION_CODE=1
```

릴리즈 절차:

1. `version.properties`의 `VERSION_NAME`과 `VERSION_CODE`를 올립니다
2. `CHANGELOG.md`에 해당 버전 항목을 추가합니다
3. 릴리즈를 냅니다. 둘 중 편한 쪽을 쓰면 됩니다.
   - `v<버전>` 태그를 밀거나 (`git tag v1.0.1 && git push origin v1.0.1`)
   - Actions 탭에서 `Release` 워크플로를 직접 실행합니다.
     태그를 비워 두면 `version.properties`의 값으로 `v<버전>` 태그를
     그 커밋에 새로 만들어 줍니다. (태그를 직접 밀 수 없는 환경에서 쓰세요.)

   어느 쪽이든 워크플로가 태그와 `version.properties`가 일치하는지 확인하고,
   테스트를 돌리고, APK를 빌드해 **GitHub 릴리즈에 첨부**합니다.
   릴리즈 노트는 `CHANGELOG.md`의 해당 항목에서 자동으로 뽑아 옵니다.

### 릴리즈 서명

저장소 시크릿에 아래 값을 넣어 두면 릴리즈 APK가 그 키로 서명됩니다.

| 시크릿 | 내용 |
| --- | --- |
| `KEYSTORE_BASE64` | 키스토어(`.jks`) 파일을 base64로 인코딩한 값 |
| `KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `KEY_ALIAS` | 키 별칭 |
| `KEY_PASSWORD` | 키 비밀번호 |

시크릿이 없으면 디버그 키로 서명해 **설치는 가능한** APK를 만듭니다.
(서명되지 않은 APK는 설치할 수 없기 때문입니다.)
